Contributing Guidelines

Welcome Contributors!

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

We appreciate your interest in improving the Simple Interest Calculator project.

How to Contribute

Fork this repository.

Clone your fork to your local machine.

Create a new branch for your changes.

Make your improvements or fixes.

Commit your changes with a clear commit message.

Push your changes to your GitHub repository.

Submit a pull request.

Reporting Bugs

If you find a bug, please open an issue and provide:

A clear description of the problem.

Steps to reproduce the issue.

Expected and actual results.

Suggestions and Improvements

You are welcome to suggest new features, improvements, and documentation updates.

Thank you for contributing!
