Simple Interest Calculator

Project Description

This project is a Simple Interest Calculator that calculates the simple interest based on the principal amount, annual rate of interest, and time period entered by the user.

Formula

Simple Interest = (Principal × Rate × Time) / 100

Input

Principal Amount

Rate of Interest

Time Period

Output

The calculated simple interest.

Technologies Used

Bash Scripting

Git

GitHub

Usage

Run the simple-interest.sh script in a terminal to calculate simple interest.
